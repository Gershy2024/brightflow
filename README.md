# Project Vault Hub | מרכז ניהול הפרויקטים והאפליקציות

מערכת דשבורד מודרנית ומרכזית לניהול, קטלוג ומעקב אחרי כל הפרויקטים והאפליקציות שפותחו, כולל מידע טכנולוגי, סביבות פריסה, מסדי נתונים, ואנשי קשר.

## ✨ תכונות מרכזיות (Features)

1. **תמיכה דו-לשונית מלאה (Bilingual Hebrew & English)**:
   * כפתור החלפת שפה בלחיצה אחת (`עב` / `EN`).
   * התאמת כיווניות מלאה (`RTL` / `LTR`).
   * גופן מותאם `Arial Rounded MT Bold` עם שילוב מודרני מעוגל.

2. **קטלוג ומידע מלא לכל פרויקט**:
   * **סטטוס פעילות**: באוויר (Live), בפיתוח, בתחזוקה, מושהה, בארכיון.
   * **קישורים**: אתר חי (Live URL), קוד (GitHub), סביבת בדיקות (Staging), ופאנל ניהול (Admin).
   * **אחסון ופריסה**: Vercel, Render, Railway, AWS, Cloudflare ועוד.
   * **בסיס נתונים**: Supabase, Neon PostgreSQL, Turso / LibSQL, MongoDB, MySQL וכו'.
   * **בעלות ואנשי קשר**: שם לקוח/ארגון, אנשי קשר כולל חיוג ישיר ושליחת וואטסאפ בלחיצה אחת.
   * **הערות פיתוח ונתיב מקומי**: גישה מהירה לקוד המקור במחשב.

3. **שלושה מצבי תצוגה גמישים**:
   * **תצוגת טבלה (Table)**: טבלה עשירה עם פעולות שורה אישיות, בדיקת לינקים מהירה, וממשק נקי.
   * **תצוגת כרטיסים (Cards)**: גריד כרטיסים מעוצב.
   * **תצוגת לוח גרירה (Kanban DND)**: גרירה והזזה חופשית של כרטיסי פרויקטים בין טורים עם `@dnd-kit` ואייקון `GripVertical`.

4. **סרגל פעולות קבוצתיות (Bulk Action Toolbar)**:
   * בחירה מרובה (Multi-Select) עם "בחר הכל".
   * שינוי סטטוס מרוכז לקבוצת פרויקטים.
   * ייצוא נבחרים לקובץ JSON.
   * מחיקה מרוכזת עם חלון אישור מאובטח.

5. **חלוקה לעמודים מבוססת ביצועים (Pagination)**:
   * בחירת כמות פריטים לעמוד (10, 25, 50, 100).
   * דפדוף חלק ותצוגת מנייה ("מציג 1-25 מתוך...").

6. **תפריטי בחירה עם חיפוש מובנה (Searchable Combobox)**:
   * בחירת סטטוס, ספק אחסון, בסיס נתונים ולקוח עם חיפוש פנימי ומצב ריק ("לא נמצאו תוצאות").

7. **סורק פרויקטים אוטומטי (Local Scanner)**:
   * סריקה חיה של התיקיות השכנות במחשב, זיהוי אוטומטי של תלויות `package.json`, הגדרות Vercel וסכמות Supabase, וייבוא בלחיצת כפתור אחת.

8. **גיבוי וייצוא נתונים**:
   * אפשרות הורדת קובץ גיבוי מלא של כל המאגר ושחזורו בכל עת.

---

## 🚀 הרצה מקומית

```bash
npm run dev
```
